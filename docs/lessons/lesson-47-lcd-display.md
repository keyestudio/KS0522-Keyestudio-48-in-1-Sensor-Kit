# レッスン47: LCDディスプレイ

> **キット:** Keyestudio 48-in-1 センサーキット  
> **ボード:** Keyestudio V4.0 / Arduino Uno互換 ATmega328P ボード

![プロジェクト47: LCDディスプレイのイラスト](../media/1aa1fd551e180d013633c1fe857c24a6.jpeg)

## 説明

このプロジェクトでは、V4.0ボードを使って0802 LCDにテキストを表示します。

LCDの表示容量は8×2文字で、チップの動作電圧は4.5～5.5Vです。

0802 LCDでテキストを表示する接続方法は、4ビット接続と8ビット接続の2通りあります。

以下の説明を参照してください。

## インターフェースの説明

| **インターフェース** | **ピン** | **説明**                                              |
| :-----------: | :-----: | ------------------------------------------------------------ |

|       2       |   VDD   | ロジック電源                                                  |

|       8       |   DB1   | データ入出力ピン                                        |

## 必要なハードウェア

まず、以下の部品を用意してください。

- V4.0ボード × 1
- 0802 LCD × 1
- ロータリーポテンショメータ × 1
- ブレッドボード × 1
- USBケーブル × 1
- ジャンパーワイヤ（必要に応じて）
- デュポン線（必要に応じて）

## ソースコード

## 4ビット接続用

```C
//////////////////////////////////////////////////////////
#include <LiquidCrystal.h>
// initialize the library with the numbers of the interface pins
LiquidCrystal lcd(11, 12, 6, 7, 4, 5);

void setup() {
  // set up the LCD's number of columns and rows:
  lcd.begin(8, 2);
  // Print a message to the LCD.
  lcd.setCursor(0, 0);
  lcd.print(" Hello");
  lcd.setCursor(0, 1);
  lcd.print(" world!");
}

void loop() {
}
//////////////////////////////////////////////////////////
```

## 8ビット接続用

```C
#include <LiquidCrystal.h>

// RS, RW, Enable, D0, D1, D2, D3, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 2, 3, 4, 5, 6, 7, 8, 9, 10);

void setup() {
  lcd.begin(8, 2);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("ABCDEFGH");
  lcd.setCursor(0, 1);
  lcd.print("12345678");
}

void loop() {
  // The 8-bit display remains static after setup.
}
```

## 実行結果

配線・電源を接続し、上記のコードをボードにアップロードします。ポテンショメータを回してLCDのバックライトを調整すると、文字がLCD画面に表示されます。

4ビット接続を使用した場合、LCDの1行目に「Hello」が、2行目に「world!」が表示されるはずです。下図のように表示されます。
