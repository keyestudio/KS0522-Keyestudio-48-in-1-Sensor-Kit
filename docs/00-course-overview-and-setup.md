# Keyestudio Kit de capteurs 48 en 1 : Aperçu du cours et configuration

![Illustration du kit de capteurs Keyestudio 48 en 1](media/714cd6e6cc87437cbdb2a0def262cc62.jpeg)

## Aperçu du cours

Ce kit de capteurs, compatible avec divers microcontrôleurs et Raspberry Pi, contient 48 capteurs et modules couramment utilisés incluant un module buzzer actif, un module relais 5V, un module de température et d'humidité et d'autres encore.

En même temps, des projets détaillés pour chaque capteur basés sur une carte de développement sont également fournis, comme les méthodes de câblage et le code de test. Avec l'aide de ce kit, vous pouvez non seulement acquérir des connaissances intéressantes à leur sujet mais aussi réaliser des projets interactifs substantiels.

Remarque : dans les projets suivants, la carte principale et d'autres fils ne sont pas inclus dans ce kit.

> **Ressources et téléchargement du code :** [Tutoriel KS0522](./Resources.7z)

## Carte de développement Keyestudio V4.0

![Illustration de la carte de développement Keyestudio V4.0](media/d48e310dbb7f60760a02fbd88c17d97a.png)

La carte de développement Keyestudio V4.0 est une carte compatible Arduino Uno, basée sur le microcontrôleur ATmega328P, et équipée d'une puce cp2102 servant de convertisseur UART vers USB.

![Illustration de la carte de développement Keyestudio V4.0](media/d1d8b8703109cc5f953ec723ac57804d.jpeg)
Elle dispose de 14 broches d'entrée/sortie numériques (dont 6 peuvent être utilisées comme sorties PWM), de 6 entrées analogiques, d'un quartz 16 MHz, d'une connexion USB, d'une prise d'alimentation, de 2 headers ICSP et d'un bouton de réinitialisation.

![Illustration de la carte de développement Keyestudio V4.0](media/bc609cfdb8f102e95dd298121e8eae01.jpeg)
Elle contient tout le nécessaire pour prendre en charge le microcontrôleur ; connectez-la simplement à un ordinateur avec un câble USB ou alimentez-la via une prise d'alimentation DC externe (DC 7-12V) ou via les headers femelles Vin/ GND(DC 7-12V) pour démarrer.

| Microcontrôleur             | ATmega328P-PU                                            |
|-----------------------------|----------------------------------------------------------|
| Tension de fonctionnement   | 5V                                                       |
| Tension d'entrée (recommandée) | DC7-12V                                              |
| Broches d'E/S numériques    | 14 (D0-D13)  (dont 6 fournissent une sortie PWM)         |
| Broches PWM numériques      | 6 (D3, D5, D6, D9, D10, D11)                             |
| Broches d'entrée analogiques | 6 (A0-A5)                                               |
| Courant DC par broche E/S   | 20 mA                                                    |
| Courant DC pour la broche 3.3V | 50 mA                                                 |
| Mémoire Flash               | 32 KB (ATmega328P-PU) dont 0.5 KB utilisé par le bootloader |
| SRAM                        | 2 KB (ATmega328P-PU)                                     |
| EEPROM                      | 1 KB (ATmega328P-PU)                                     |
| Fréquence d'horloge         | 16 MHz                                                   |
| LED_BUILTIN                 | D13                                                      |

## Exigences des bibliothèques

> **Sécurité et configuration.** Déconnectez l'alimentation avant de modifier le câblage. N'utilisez le projet du relais qu'avec des charges basse tension sauf si une isolation appropriée, un boîtier et des pratiques de sécurité secteur sont en place. Sélectionnez **Arduino Uno** dans l'IDE Arduino avant de compiler les exemples pour la carte V4.0.

La plupart des exemples n'utilisent que le cœur standard d'Arduino. Installez les bibliothèques suivantes avant de compiler les projets correspondants. Le package contient également des copies héritées sous `Resources/02. libraries/` pour les projets dont le code cible d'anciennes API de bibliothèques.

| Projets | Bibliothèque requise | Instructions d'installation |
| --- | --- | --- |
| 33–34 | `IRremote` | Installez **IRremote** depuis le gestionnaire de bibliothèques de l'IDE Arduino. |
| 40 | `DHTlib` | Installez **DHTlib** depuis le gestionnaire de bibliothèques de l'IDE Arduino. L'exemple ci-dessous utilise son API actuelle `dht.h`. |
| 42 | `SparkFun_APDS9960` | Utilisez la bibliothèque fournie `Resources/02. libraries/SparkFun_APDS9960` après avoir confirmé que le matériel est APDS-9960. |

| 48 | `Adafruit LED Backpack Library` and `Adafruit GFX Library` | Installez les deux bibliothèques depuis le gestionnaire de bibliothèques de l'IDE Arduino. |
