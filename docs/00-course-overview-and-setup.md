# Keyestudio 48-in-1 Sensor Kit: Kursübersicht und Einrichtung

![Keyestudio 48 in 1 Sensor Kit Abbildung](media/714cd6e6cc87437cbdb2a0def262cc62.jpeg)

## Kursübersicht

Dieses Sensor-Kit, das mit verschiedenen Mikrocontrollern und dem Raspberry Pi kompatibel ist, enthält 48 häufig verwendete Sensoren und Module, darunter ein aktives Summer-Modul, ein 5V-Relais-Modul, ein Temperatur- und Feuchtigkeitsmodul und weitere.

Gleichzeitig werden für jeden Sensor einige detaillierte Projekte auf Basis eines Entwicklungsboards bereitgestellt, z. B. Verdrahtungsmethoden und Testcode. Mit Hilfe dieses Kits können Sie nicht nur interessantes Wissen über die Komponenten erwerben, sondern auch umfangreiche interaktive Projekte erstellen.

Beachten Sie, dass in den folgenden Projekten das Hauptboard und zusätzliche Leitungen nicht in diesem Kit enthalten sind.

> **Ressourcen und Code-Download:** [KS0522 Anleitung](./Resources.7z)

## Keyestudio V4.0 Entwicklungsboard

![Abbildung des Keyestudio V4.0 Entwicklungsboards](media/d48e310dbb7f60760a02fbd88c17d97a.png)

Das Keyestudio V4.0 Entwicklungsboard ist ein mit dem Arduino Uno kompatibles Board, das auf dem ATmega328P MCU basiert und einen CP2102-Chip als UART-zu-USB-Wandler besitzt.

![Abbildung des Keyestudio V4.0 Entwicklungsboards](media/d1d8b8703109cc5f953ec723ac57804d.jpeg)
Es verfügt über 14 digitale Ein-/Ausgangspins (davon 6 als PWM-Ausgänge nutzbar), 6 analoge Eingänge, einen 16-MHz-Quarzoszillator, eine USB-Verbindung, eine Strombuchse, 2 ICSP-Header und einen Reset-Taster.

![Abbildung des Keyestudio V4.0 Entwicklungsboards](media/bc609cfdb8f102e95dd298121e8eae01.jpeg)
Es enthält alles, was zur Unterstützung des Mikrocontrollers erforderlich ist; verbinden Sie es einfach mit einem Computer über ein USB-Kabel oder versorgen Sie es über eine externe DC-Strombuchse (DC 7-12V) oder über die Female-Header Vin/ GND(DC 7-12V), um zu starten.

| Mikrocontroller             | ATmega328P-PU                                            |
|-----------------------------|----------------------------------------------------------|
| Betriebsspannung            | 5V                                                       |
| Eingangsspannung (empfohlen)| DC7-12V                                                  |
| Digitale I/O-Pins           | 14 (D0-D13)  (davon 6 bieten PWM-Ausgang)                |
| PWM-fähige digitale I/O-Pins| 6 (D3, D5, D6, D9, D10, D11)                             |
| Analoge Eingangspins        | 6 (A0-A5)                                                |
| Gleichstrom je I/O-Pin      | 20 mA                                                    |
| Gleichstrom für 3.3V-Pin    | 50 mA                                                    |
| Flash-Speicher              | 32 KB (ATmega328P-PU) davon 0.5 KB vom Bootloader genutzt|
| SRAM                        | 2 KB (ATmega328P-PU)                                     |
| EEPROM                      | 1 KB (ATmega328P-PU)                                     |
| Taktfrequenz                | 16 MHz                                                   |
| LED_BUILTIN                 | D13                                                      |

## Benötigte Bibliotheken

> **Sicherheit und Einrichtung.** Trennen Sie die Stromversorgung, bevor Sie die Verdrahtung ändern. Verwenden Sie das Relaisprojekt nur mit Niederspannungs-Lasten, sofern nicht geeignete Isolation, Gehäuse und Netzsicherheitsmaßnahmen vorhanden sind. Wählen Sie vor dem Kompilieren von Beispielen für das V4.0-Board in der Arduino-IDE **Arduino Uno** aus.

Die meisten Beispiele verwenden nur den Standard-Arduino-Core. Installieren Sie die folgenden Bibliotheken, bevor Sie die entsprechenden Projekte kompilieren. Das Paket enthält außerdem Legacy-Kopien unter `Resources/02. libraries/` für Projekte, deren Code auf ältere Bibliotheks-APIs abzielt.

| Projekte | Erforderliche Bibliothek | Installationshinweis |
| --- | --- | --- |
| 33–34 | `IRremote` | Installieren Sie **IRremote** über den Library Manager der Arduino-IDE. |
| 40 | `DHTlib` | Installieren Sie **DHTlib** über den Library Manager der Arduino-IDE. Das folgende Beispiel verwendet dessen aktuelle `dht.h`-API. |
| 42 | `SparkFun_APDS9960` | Verwenden Sie die mitgelieferte `Resources/02. libraries/SparkFun_APDS9960`-Bibliothek, nachdem Sie bestätigt haben, dass die Hardware APDS-9960 ist. |
| 43 | `APDS9930` | Verwenden Sie die mitgelieferte `Resources/02. libraries/APDS9930_`-Bibliothek, nachdem Sie bestätigt haben, dass die Hardware APDS-9930 ist. |
| 44 | `SparkFun_MMA8452Q` | Verwenden Sie die mitgelieferte `Resources/02. libraries/SparkFun_MMA8452Q_Arduino_Library_master`-Bibliothek. |
| 48 | `Adafruit LED Backpack Library` und `Adafruit GFX Library` | Installieren Sie beide Bibliotheken über den Library Manager der Arduino-IDE. |
